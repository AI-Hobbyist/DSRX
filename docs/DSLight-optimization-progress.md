# DSLight 优化目标与进度

日期：2026-11-12。用户已授权实现五个优先方向。范围限定 DSLight，保留原架构 checkpoint、训练与受支持部署行为；新容量配置需独立训练，量化质量需授权校准/评估数据。

按以下顺序完成，每个阶段自动验证通过后检查差异、单独提交并推送，再进入下一阶段：

1. 条件投影跨采样步缓存。原生 eager Reflow/DDPM 已接入局部预计算，五项骨干回归通过（数值、参数预算、trace、乐句隔离、RK2 每次采样仅投影一次）。训练和既有导出入口保留普通条件路径；trace 后不保留准备接口的模块仍走普通路径。进入独立提交/推送检查点。
2. 时间编码频率预存与逐元素融合已实现：FP32 非持久化频率缓存随设备转换重建，低精度保留原有计算顺序；eval 调制使用 addcmul，训练表达保持原样。七项回归通过，包括精度往返和训练/eval 等价性。门控后的大投影不拆成两次卷积，避免增加算子；尚未宣称实测提速。进入独立提交/推送检查点。
3. 通道容量实验已实现 scripts/profile_dslight_width.py，生成独立重训配置并保持层数/感受野一致。CPU 单线程、256帧、20次中位数：128/160/192通道分别922240/1413888/2009984参数，12.56/16.29/19.92 ms。128通道比当前160少约34.8%参数、该随机权重骨干微基准耗时少约22.9%，尚不证明歌声质量不降；保持现有160权重默认，不进行不严格加载。artifacts/dslight_width/report.json保留环境与口径。进入提交/推送检查点。
4. scripts/evaluate_dslight_sampling.py 已使用真实权重、原始留出音频及配套字典严格加载完成评估。唯一配置留出样本2033001224：起点0.4的4/8/20步MAE为0.52248/0.54938/0.57293；辅助输出MAE0.45543；对应实际NFE4/8/20，辅助路径NFE0。结果artifacts/dslight_sampling/sampling.json包含SHA256、设备、逐项耗时与范围说明，sample_0.pt保留真实评估特征供量化复用。该样本更多步数未改善重建误差，不改默认步数，不能外推听音优劣。MANUAL/PENDING：听音；重建指标不等同完整SVS质量。进入提交/推送检查点。
5. 选择性INT8权重存储、独立包格式及严格回载已实现，保留时间/depthwise/输出浮点。两项量化测试、原opset15动态帧ONNX测试通过；真实留出特征CPU比较和五个声码器对照音频完成。声学包26,335,459→22,535,435字节（-14.4%），缓存FP32约0.39990秒、量化约0.42928秒，量化目标MAE0.59342 vs FP32 0.58856，因此保持量化可选、不默认启用。完整范围与待验证事项见DSLight-optimization-results.md。进入提交/推送检查点。
